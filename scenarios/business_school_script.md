## 一、关卡信息

- **关卡 ID**：DLC02-L01
- **名称**：招生咨询面谈（公开课后的 15 分钟）
- **前置**：学员（潜在学员）已参加公开课，印象不错
- **目标**：识别学员类型 → 挖出真实动机与核心顾虑 → 匹配产品 → 约定下一步（提交材料/约深度咨询）
- **结局**：✅ 约定下一步（高/低热度）｜❌ 失败（"我再考虑考虑"）
- **语音**：三类学员各配置（见台词库）

## 二、三类学员 persona（随机出现）

### A 周总（民营中小企业主）· 女声不需要，男声 zh-CN-YunjianNeural · rate -5%
- **开场**（公开课刚结束，主动凑过来）："老师讲得倒是有点意思，就是不知道我们这种小厂能不能用上。你贵姓？"
- **表层需求**：学 AI 怎么用
- **真实动机**：厂里管理乱、被同行卷、想找出路但怕被割韭菜
- **核心顾虑**：钱（学费）、时间（厂里离不开人）、实效（学了用不上）
- **打动点**：证明"能落地、先小范围试"；尊重他的实践经验
- **防御点**：听理论术语、"你们学校就爱卖课"、催缴费

### B 林女士（外企中层）· 女声 zh-CN-XiaoxiaoNeural · rate 0%
- **开场**："你好，我是朋友介绍来的。今天讲得挺有启发，想问下你们这个班具体怎么安排？"
- **表层需求**：了解课程安排
- **真实动机**：想升 VP，需要"系统性背书"+ 证书 + 校友圈（暗含换平台想法）
- **核心顾虑**：公司预算审批（要写报告）、时间冲突（出差多）、"和别的商学院有什么不一样"
- **打动点**：量化职业回报、校友案例、证书认可度；帮她"说服公司"（话术支持）
- **防御点**：官网式介绍、催报名、说"大家都报"

### C 小陈（家族企业二代）· 男声 zh-CN-YunxiNeural · rate -10%
- **开场**：（有点犹豫）"嗯……我爸让我来听听的。你们这班，都是些什么人在上？"
- **表层需求**：看看同学都是谁
- **真实动机**：想证明自己（父辈+老臣子盯着）、补公司治理与新商业知识、找同龄圈层
- **核心顾虑**：显得"被安排"、怕同学层次低、基础够不够（自尊）
- **打动点**：把他当"已经在独当一面的管理者"尊重；介绍同学构成（企业家二代/创业者）；不急着推销
- **防御点**：把他当小孩/富二代对待、"让你爸给你报"、轻视他的经验

## 三、状态机（沿用单人关，按类调整）

- 开放度 O（初始：公开课好感 → 中高 30）｜信任度 T（初始 20）｜决策倾向 P（0-100）
- 推进判定：O≥70 且 P≥60 → 约定下一步
- 失败判定：红线≥2（介绍项目/催报名/贬低学员）或关键节点未正确提问 3 次

## 四、分支点

### B0 开场（回合 1-2）
学员主动/被动开场。教练按 persona 开场白回应。
| 顾问行为 | 反应 |
| --- | --- |
| 问动机（"今天听完，哪一点让您觉得有共鸣？"）✅ | 学员说出真实兴趣点（如周总"讲到排产那一段"） |
| 泛问（"您对我们哪个班感兴趣？"）⚠️ | 学员敷衍（"先了解一下"） |
| 介绍课程（"我们师资多厉害"）🔴 | 学员（周总）："这些我在宣传册上都看过了。" |

### B1 挖动机（回合 3-6）
| 顾问行为 | 反应 |
| --- | --- |
| 三问（"您说想学 AI，具体是厂里哪块让您烦？"）🎯 | 周总说出"管理乱、人难招"；林女士说出"想往上走"；小陈说出"想证明自己" |
| 问现状（"您现在团队/工作怎么分工？"）✅ | 学员描述现状（开放+） |
| 直接推产品（"我们 MBA 最适合您"）🔴 | 防御（"你怎么知道适合我？"） |

### B2 挖顾虑（回合 7-10）
| 顾问行为 | 反应 |
| --- | --- |
| 问顾虑（"如果真的考虑报名，您觉得最大的障碍会是什么？"）✅ | 周总："学费和时间"；林女士："公司预算"；小陈："我爸会不会觉得我又乱花钱" |
| 问过去经验（"您之前上过类似的课吗？"）✅ | 暴露过往不满（"上过，讲的都是理论"）→ 给对症机会 |
| 直白问"不报名还担心什么"⚠️ | 学员含糊（"没有，我再想想"）——压迫感 |

### B3 对症与匹配（回合 11-14）
| 顾问行为 | 反应 |
| --- | --- |
| 给实证（"上期有个学员也是机械厂，他把老师请去厂里做过一次诊断……"）✅ | 周总认真听 |
| 帮林女士算账（"如果你要写报告给 HR，我可以给你一份项目 ROI 摘要"）🎯 | 林女士："这个倒是实用。" |
| 尊重小陈（"您在公司已经负责哪块？"）🎯 | 小陈放松（"我管供应链"） |
| 催报名/价格战 🔴 | 学员："我再考虑考虑" |

### B4 约定下一步（回合 15-18）
- ✅ 高热度：约深度咨询/提交材料/参加下期公开课（学员主动问时间）
- ✅ 低热度：答应"发资料+两周后回访"
- ❌ 失败：学员"我回去想想"，无下一步

## 五、结局

| 结局 | 表现 | 练习重点 |
| --- | --- | --- |
| ✅ 高热度推进 | 学员主动约时间/要材料清单 | 平常心确认+明确下一步 |
| ✅ 低热度推进 | 留联系方式+承诺跟进 | 留触点（可再邀公开课） |
| ❌ 失败 | "我再想想" | 复盘：哪一步没问到位 |
