# cheatsheet — 提问销售法速查表

> 场景 → 动作，一屏速查。来源页码见 references 各文件。

## 场景 → 动作
| 场景 | 立即动作 |
| --- | --- |
| 开场 | 3 秒提问："您听说过我们吗？"+"为什么愿意见我？" |
| 推进 | 三问："比如说？"→"为什么？"→"也就是说？" |
| 被拒 | 先理解再切题："那挺好的"+"剩下的部分呢？" |
| 谈方案 | 走四步：现状→需求→问题→方案（方案最后给） |
| 签单 | 平常心："也就是说，您决定与我们合作了？" |
| 售后 | 主动回访："用起来怎么样？"（"没变化"也要追问） |

## 三问卡
- **比如说？** —— 展开具体信息
- **为什么？** —— 挖深层动机（可连环）
- **也就是说？** —— 确认想法、推进行动
- 过去的事补："后来怎么样了？"

## 四步卡
了解现状 → 挖掘需求 → 发现问题 → 解决问题（循环）

## 被拒三式卡
1. 共鸣 + 提问
2. 共鸣 + 称赞 + 提问
3. 共鸣 + 称赞 + 说明 + 提问

## 红线（违反即掉回"说服性销售"）
- ❌ 客户没问就介绍产品
- ❌ 被拒后补证据 / 哀求 / 降价
- ❌ 替客户下结论
- ❌ 成交即失联
- ✅ 记不住别的就记住：**多问少说，先认同再提问**
