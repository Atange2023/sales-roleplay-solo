# 《关卡复盘报告》示例 — DLC01-L02 三人方案会

> 示例：基于 2026-08-02 实际演练填写（教练视角），供模板使用参考。

## 一、关卡信息

- **关卡**：DLC01-L02 第二次现场会议（三人方案会）
- **场景**：带"老师傅参与式 AI 排产方案"二次拜访；张总+老赵+老王在场
- **结局**：✅ 通关（有条件推进——约下周三敲定细节）
- **回合数**：6 / 20（提前收官）

## 二、综合表现评分

| 维度 | 得分 | 依据 |
| --- | --- | --- |
| 提问率 | 5/5 | 全程以问句推进；仅 1 处陈述（"传统软件落后"，见优化） |
| 身份保持 | 4/5 | 未介绍产品、未逼单、未补证据（红线 0 次）；扣 1 分因"结论前置" |
| 四步推进 | 4/5 | 现状（交付延期）→ 需求（损失量化）→ 问题（老师傅不信电脑）由客户说出 → 方案（分期验收） |
| 多角色覆盖 | 5/5 | 三人都被问到；老王被请教、老赵被给定位 |
| 影响力结果 | 5/5 | 张总 +2→+3；老赵 -1→+1；老王 -2→+1 |
| **总分** | **23/25** | 🥇 段位参考：黄金 |

## 三、优点肯定

1. **回合 1**：开场先请教老王、再邀老赵——"先听一线专家的"姿态，多角色覆盖满分，奠定全场温度。
2. **回合 4**："AI 是专家的辅助，责任在您把控中""我们是来调教电脑，不是服从电脑"——金句+给定位，直接化解老赵话语权恐惧（-2→0）与老王被取代焦虑。
3. **回合 5**：把决策权交还张总（"您看这样安排可以吗"），不越级拍板，让张总有台阶单独聊。
4. **回合 6**：分期付款 30/30/30/10 与里程碑绑定，具体、可验证——回应"凭什么信你"的信任测试。

## 四、优化意见

1. **回合 3**："传统软件落后了，需要 AI 帮助"是结论前置——当众否定现状=刺激老赵话语权（-2）。
   - 修正示范："赵主任，您觉得现在这套排产方式，最大的短板在哪？"（让客户自己说出需要改变）
2. **回合 6**：报出分期结构但**未主动报总金额**——张总务实，签约前必问"一共多少钱"。
   - 修正示范："按试点范围，总投入约 XX 万，第一期启动款不到三成。"（预算透明+可控感）
3. 话术提示："最大诚意"偶尔用有力，反复用显廉价——换成具体承诺（"启动款压到三成以下，先跑通再说"）。
