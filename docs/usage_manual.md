   - "我要练销售开场" 或 "/sales-roleplay-solo"
   - 教练（Reasonix）会自动按剧本扮演数字人客户，播放语音，陪您打关

> 来源方式二选一：`git clone https://github.com/Atange2023/sales-roleplay-solo.git` 后复制；或直接解压他人转发的完整压缩包。

## 一、系统是什么

本系统是一个"销售对话模拟器"：**数字人客户会开口说话**（真人语音），陪您把《销售就是会提问》中的"提问销售法"练成行为——不是听课，是实战。

像玩游戏一样组织训练：

```
① 选行业（DLC）→ ② 选关卡 → ③ 打关（与数字人对话）→ ④ 通关/失败 → ⑤ 复盘报告
```

当前已上线 3 个关卡（见第三节），台词、语音、复盘模板全部预置。

## 二、环境准备（一次性，约 10 分钟）

### 2.1 需要的软件

| 软件 | 用途 | 说明 |

| Python 3.11+ | 运行脚本 | 本机已装（用 `py` 命令启动） |

```

```

两个都有输出 = 环境就绪。缺哪个装哪个：
- 缺 edge-tts：`py -m pip install edge-tts`
- 缺 ffplay：安装 FFmpeg（gyan.dev 版本自带 ffplay）

> 💡 如果只想练"文字版"（不听语音），第 2 步可跳过——不装语音也能跑，教练直接贴台词文字即可。

## 四、快速开始（三步）

### 第 1 步：生成客户语音（一次性）

打开 Git Bash（或 PowerShell），进入系统目录后运行：

```bash
cd "11_learning/books/销售就是会提问/14_语音陪练系统"
py 03_tts_播放.py --batch      # 生成张总 51 句（audio/ 文件夹）
py 03_tts_播放.py --batch3     # 生成三人会 48 句（audio3/）
py 03_tts_播放.py --batch4     # 生成商学院 46 句（audio4/）
```

> 本机已预生成全部语音（145 句），此步可跳过；只有在改了台词后需要重跑。

### 第 2 步：选关卡

由教练按"选关 → 打关 → 复盘"流程启动。想练哪关，告诉教练即可，例如：
- "练 DLC02 商学院，周总"
- "练三人方案会"

### 第 3 步：开练

教练播放数字人第一句语音（您会听到客户开口）→ 您打字/开口回应 → 教练判定并按剧本演下一句 → 如此循环直到结局。

> 每 3–4 回合教练会做一次三维度点评（提问率/身份保持/四步推进），通关或失败后输出《关卡复盘报告》。

## 五、打关规则（学员须知）

### 5.1 目标

每关目标不同（见关卡表），共同点是：**用提问代替介绍**，让客户自己说出需求。

### 5.2 三条红线（违反即扣分）

| 红线 | 例子 |
| --- | --- |
| ① 介绍产品/项目优点 | "我们师资很强、排名前十……" |
| ② 逼单/催报名 | "今天报名有优惠，定下来吧" |
| ③ 被拒后补证据 | 客户说"不需要"，您继续"可是我们……" |

红线累计 2 次 = 提前收场；关键节点教练提示 3 次未修正 = 判定失败（都算"通关失败"，进入复盘）。

### 5.3 状态与结局

- 教练暗中记录客户的"防御度/信任度/开放度"，达标才会推进
- 三种结局：✅ 约下一步（高/低热度）｜❌ 失败（"我再考虑考虑"）

## 六、教练操作手册（教练须知）

### 6.1 准备

1. 读对应关卡剧本（`01/15/21_剧本库_*.md`），熟悉角色卡、状态机、分支判定表
2. 记初始状态（各剧本第一节有）
3. 打开台词库（`02/16/22_台词数据库_*.json`）或直接播放预合成语音

### 6.2 打关循环

```
学员发言 → 对照"行为触发点判定表"匹配分支 → 从台词库选回应（变体轮换）
→ 播放对应 audio 文件（或用 --play 即时播放）→ 更新状态 → 学员继续
```

播放单句台词：

```bash
py 03_tts_播放.py --play B3_loss          # 播放张总"问损失"回应
py 03_tts_播放.py --play B1_why_zhous     # 播放周总"挖动机"回应
```

即时合成任意句子（台词库没有时用）：

```bash
py 03_tts_播放.py "客户罚钱加退单，少说二三十万。"
py 03_tts_播放.py "……" --voice zh-CN-XiaoxiaoNeural --rate +0%   # 换女声
```

### 6.3 复盘（通关/失败都做）

按 `18_复盘报告模板.md` 填写：六维评分 → 优点 ≥2 条（引用回合）→ 优化 ≥2 条（含修正示范）→ 红线记录 → 理论出处 → 下次建议。模板已提供完整理论出处映射表（原书页码 + 延伸学习关键词）。

## 八、常见问题（FAQ）

| 问题 | 处理 |
| --- | --- |
| 听不到语音？ | ① 确认 ffplay 已装（`ffplay -version`）；② 确认音频文件存在（`ls audio/`）；③ 手动播放测试：`ffplay audio/B3_loss_1.mp3` |
| 报错 `NoAudioReceived`？ | edge-tts 网络波动，脚本已自动重试 3 次；仍失败则稍后重跑 `--batch*` |
| 语音音色不喜欢？ | 改台词库 JSON 中该角色的 `voice`/`rate`（可用声线见脚本注释），重跑对应 `--batch` |
| 学员不知道说什么？ | 教练给 2 个可选开口方向（不代答） |
| 台词库没有我要的句子？ | 用即时合成：`py 03_tts_播放.py "新句子"` |
| 断网了能练吗？ | 能——预合成语音在本地；文字模式永远可用 |
| 换了电脑怎么迁移？ | 整个 `14_语音陪练系统/` 文件夹拷走，重装 edge-tts 即可 |

## 九、扩展指南（新增行业/关卡）

1. 复制现有剧本+台词库做模板（如 `21/22` 商学院）
2. 写角色卡（表层/真实动机/核心顾虑/打动点/防御点）
3. 填分支判定表（学员行为 → 角色反应 → 状态变化）
4. 配 voice/rate（edge-tts 中文声线见脚本注释）
5. 在 `17_关卡系统设计.md` 关卡表登记 → 即可被选关
6. 先由教练试跑一遍验证判定表，再开放给学员

## 附录：方法论速查（训练期间常用）

| 场景 | 立即动作 |
| --- | --- |
| 开场 | 3 秒提问 + "为什么愿意见我" |
| 推进 | 三问："比如说？→为什么？→也就是说？" |
| 被拒 | 先理解再切题："那挺好的" + 新问题 |
| 挖需求 | 四步：现状→需求→问题→方案（方案最后给） |
| 怕被割韭菜 | 给实证案例（同行/真实结果），不打包票 |
| 讲术语被问"啥意思" | 翻译成生活比喻（"像手机 App"） |
| 想推进签约 | 先给善意（体验/试用不设门槛），再谈流程 |
